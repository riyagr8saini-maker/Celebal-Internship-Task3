# Task 3: Superstore Sales Analysis

## Objectives
- Apply Subqueries, CTEs, and Window Functions to analyze sales data.

## Key Insights
- **Above-average sales orders**: Identified orders exceeding dataset average.
- **Highest order per customer**: Found each customer’s largest single purchase.
- **Total sales per customer**: Aggregated sales to highlight top spenders.
- **Customer rankings**: Ranked customers using RANK, DENSE_RANK, and ROW_NUMBER.
- **Final analysis**: Combined CTE + Window Functions to produce a ranked leaderboard.

## Business Findings
- Top customers contribute significantly to revenue.
- Several customers have only single orders (low engagement).
- Above-average sales orders are concentrated in specific regions and categories.
